# 일일 작업 프롬프트 템플릿

---

## 1. 개발 시작 프롬프트

```
docs/plan.md 를 참고해서 다음 Day 작업을 진행하자. 구체적인 진행 프로세스 알려줘. 개발 과정에선 AI를 적극 활용할 것.
```

---

## 2. 개발 완료 후 문서 작업 프롬프트

```
오늘 작업이 끝났어. docs/plan.md와 README.md를 확인해서 현재 Day를 파악하고, 아래 문서 작업을 모두 진행해줘.

1. docs/plan.md — 해당 Day에 ✅ 체크 표시
2. README.md — Progress 섹션 해당 Day 체크
3. docs/blog/retrospective/{번호}-day{N}.md — 오늘 진행한 step 순서대로 회고 작성 (삽질 포함)
4. docs/blog/ai-dev-experience/{번호}-day{N}.md — AI 활용 경험 정리 (프롬프트 예시, 코드 예시, AI 기여도 포함)
5. (이슈가 있었다면) docs/troubleshooting/{날짜}-{이슈명}.md — 트러블슈팅 문서 작성
```
