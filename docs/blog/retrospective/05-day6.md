# 2주 만에 AI 서비스 만들기 — Day 6 회고

## 오늘의 목표

- Backend Render 배포
- Frontend Vercel 배포
- 실서비스 동작 확인

---

## Step 1: Backend Render 배포

Render에서 GitHub repo 연결 → Docker 런타임 선택 → 환경변수 설정 → 배포.

환경변수:
- `CLAUDE_API_KEY`: Claude API 키
- `SPRING_PROFILES_ACTIVE`: prod
- `CORS_ALLOWED_ORIGINS`: Vercel 프론트 URL

배포 후 `/` 경로에 404 로그가 찍혔는데, Render 헬스체크가 루트에 요청을 보내서 발생한 것. API 엔드포인트(`/api/summarize`)는 정상 동작.

---

## Step 2: Frontend Vercel 배포

### 삽질: 404 Not Found

Vercel 배포 후 접속하면 404가 떴다. 빌드는 성공했는데 페이지가 안 나오는 상황.

**원인:** Framework Preset이 `Other`로 설정되어 있었음. `Next.js`로 변경하니 즉시 해결.

**교훈:** Vercel에서 Next.js 프로젝트를 배포할 때 Framework Preset이 자동 감지되지 않으면 수동으로 지정해야 한다. Root Directory를 `frontend`로 설정한 경우 자동 감지가 안 될 수 있음.

### 추가 이슈: lockfile 충돌 경고

프로젝트 루트에 빈 `package-lock.json`이 있어서 Vercel이 workspace root를 잘못 추론하는 경고가 발생. 해당 파일 삭제로 해결.

---

## Step 3: CORS 설정

초기에 `CORS_ALLOWED_ORIGINS=*`로 임시 설정 후, Vercel URL 확정 후 `https://ai-summarize-sigma.vercel.app`으로 변경.

---

## Step 4: 실서비스 E2E 확인

Vercel URL 접속 → 텍스트 입력 → 요약 결과 정상 표시 확인.
