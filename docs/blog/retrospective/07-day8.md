## Step 1: PDF 업로드 — 백엔드

PDFBox 3.0.7 의존성 추가 + `POST /api/summarize/pdf` 엔드포인트 생성.

```java
@PostMapping("/summarize/pdf")
public SummarizeResult summarizePdf(@RequestParam("file") MultipartFile file) throws Exception {
    // PDF → 텍스트 추출 → 500자 잘라서 기존 요약 로직 호출
    try (PDDocument doc = Loader.loadPDF(file.getBytes())) {
        text = new PDFTextStripper().getText(doc);
    }
}
```

### 삽질 1: Gradle 빌드 SSL 에러

PDFBox 의존성 추가 후 `trustAnchors parameter must be non-empty` 에러 발생. Gradle Daemon도 별도 JVM이라 trustStorePassword가 필요했다. `gradle.properties`에 설정 추가로 해결.

### 삽질 2: 파일 크기 제한

기본 업로드 제한이 1MB라 PDF 업로드 시 `MaxUploadSizeExceededException` 발생. `application.properties`에 10MB로 상향.

## Step 2: PDF 업로드 — 프론트엔드

- 탭 전환 UI (텍스트 입력 / PDF 업로드)
- 파일 선택 클릭 + 드래그앤드롭 지원
- 드래그 시 영역 하이라이트 (파란색 보더 + 배경)

---

## Step 3: 요약 결과 복사 버튼

각 카드(요약/핵심포인트/액션) 오른쪽 상단에 "복사" 버튼 추가. 클릭 시 클립보드 복사 + "✓ 복사됨" 2초간 피드백.

---

## Step 4: 입력 예시 텍스트

글자 수 카운터 왼쪽에 "예시 텍스트로 시도" 버튼 추가. 클릭 시 AI 관련 샘플 텍스트가 textarea에 채워짐.
