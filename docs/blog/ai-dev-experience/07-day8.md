## 2. PDF 프론트엔드

```
step2 시작 (PDF 업로드 프론트엔드 UI)
```

- 탭 전환 (텍스트/PDF)

## 4. Gradle SSL 디버깅

### 상황

PDFBox 의존성 추가 후 빌드 시 `trustAnchors parameter must be non-empty` 에러.

### AI 진단

"Gradle Daemon도 별도 JVM이라 trustStorePassword 설정이 필요하다"고 즉시 진단. `gradle.properties` 파일로 해결.

이전 Day 2, 5에서 같은 류의 문제를 겪었기 때문에 AI가 패턴을 인식하고 빠르게 해결.

### 오늘 배운 것

- **기능을 작은 단위로 쪼개서 요청하면 AI 정확도가 높다.** "PDF 업로드 전체 구현해줘"보다 백엔드/프론트/드래그앤드롭을 분리해서 요청하니 수정 없이 동작.
- **이전 문제의 패턴을 AI가 기억한다.** 같은 세션에서 SSL 문제를 여러 번 겪으니 세 번째는 즉시 해결.
- **Spring Boot 파일 업로드 기본 제한(1MB)은 자주 놓치는 부분.** properties 설정으로 간단히 해결 가능.
