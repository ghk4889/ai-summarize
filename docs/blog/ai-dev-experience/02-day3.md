## 1. 프롬프트 설계

### 요구사항 → AI에게 전달한 내용

```
Claude API의 system 프롬프트를 만들어줘.
- 사용자가 텍스트를 보내면 JSON으로 응답
- 형식: {"summary": "...", "keyPoints": [...], "actions": [...]}
- 마크다운 없이 순수 JSON만 반환
```

### AI가 생성한 프롬프트

```
You are a document summarizer. Analyze the given text and respond with ONLY a JSON object in this exact format:
{"summary":"A concise 2-3 sentence summary","keyPoints":["key point 1","key point 2","key point 3"],"actions":["action item 1","action item 2"]}
Rules: summary is a brief overview. keyPoints are the most important facts (3-5 items). actions are actionable next steps if any (0-3 items, empty array if none). Respond with ONLY the JSON, no markdown or explanation.
```

### 실제 결과와 문제

프롬프트에 "no markdown"이라고 명시했지만, Claude가 `` ```json `` 코드블록으로 감싸서 응답했다.

**교훈:** LLM에게 "하지 마"라고 해도 100% 지켜지지 않는다. 방어 코드가 필수.

```java
content = content.strip();
if (content.startsWith("```")) {
    content = content.replaceFirst("```(?:json)?\\s*", "");
    content = content.replaceFirst("\\s*```$", "");
}
```

## 2. Next.js UI 생성

### 프롬프트 예시

```
Next.js + TailwindCSS로 AI 요약 서비스 메인 페이지를 만들어줘.
- textarea로 텍스트 입력
- "요약하기" 버튼
- 결과를 summary / keyPoints / actions 카드로 표시
- 로딩 상태, 에러 표시 포함
- API 엔드포인트: POST http://localhost:8080/api/summarize
- 과하지 않은 최소한의 스타일
```

### AI가 생성한 결과

100줄짜리 `page.tsx` 하나로 전체 UI 완성. useState로 상태 관리, fetch로 API 호출, 조건부 렌더링으로 로딩/에러/결과 표시.

수정 없이 바로 동작했다. 프론트엔드 코드 생성은 AI가 가장 잘하는 영역 중 하나.

## 3. CORS 디버깅

### 상황

브라우저에서 "Failed to fetch" 에러 발생. 브라우저 콘솔에 CORS 관련 에러.

### AI에게 전달

```
브라우저에서 요약하기 버튼 눌렀는데 Failed to fetch 에러 발생. 디버깅해줘.
```

### AI의 진단

즉시 CORS 문제로 진단하고 `@CrossOrigin` 어노테이션 추가. 정확했다.

## Day 3 AI 활용 총평

| 작업 | AI 기여도 | 비고 |
|------|----------|------|

| Next.js UI | 95% | 수정 없이 바로 동작 |

| 마크다운 파싱 이슈 | 50% | 원인은 AI가 진단, 해결 패턴도 AI가 제안 |

### 오늘 배운 것

- **프롬프트 설계 시 "하지 마" 보다 방어 코드가 확실하다.** LLM 출력은 비결정적이므로 파싱 전 전처리는 기본.
- **프론트엔드 UI 생성은 AI의 최강 영역.** 명확한 요구사항만 주면 수정 없이 동작하는 코드가 나온다.
- **에러 메시지를 그대로 AI에게 주면 디버깅이 빠르다.** 스택트레이스 전체를 붙여넣는 게 효과적.
